# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Evil-WinRM, please report it privately. Do not open a public issue, discussion, pull request, or otherwise disclose the vulnerability before the coordinated disclosure process has been completed.

Please include enough information for the issue to be assessed and reproduced, such as the affected version, impact, affected functionality, prerequisites, and reproduction steps. As part of responsible disclosure, proofs of concept or payloads must be shared only through the agreed private communication channel and must not be published or shared with third parties during the coordinated disclosure process.

Please allow the maintainers reasonable time to investigate, reproduce, remediate, and release a fix before making any information public.

## Coordinated Disclosure Process

If the vulnerability is confirmed, the maintainers may open a draft GitHub Security Advisory and invite the reporter as a collaborator. The advisory can then be used to coordinate remediation, verification, credit, and disclosure timing.

The maintainers will develop and verify a fix and make it available in a patched Evil-WinRM release. Once the patched release is available, the GitHub Security Advisory will be published with the appropriate technical and remediation information. Working payloads or other unnecessarily actionable exploitation details may be omitted from the published advisory.

When appropriate, the maintainers may request a CVE identifier through GitHub. CVE assignment is handled by the relevant authority and cannot be guaranteed by the Evil-WinRM project.

The reporter must keep the vulnerability and all related technical details private until the maintainers confirm that coordinated disclosure can proceed.

## Supported Versions

Security fixes are provided only for the latest stable Evil-WinRM release available from the `master` branch. Development, beta, testing, legacy, or otherwise modified versions are not supported.
